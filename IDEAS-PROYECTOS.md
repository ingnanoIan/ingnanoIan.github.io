# Guía para tus primeros proyectos de datos

## Qué buscan quienes revisan un portafolio de datos
- Que sepas llevar un proyecto de principio a fin: obtener datos, limpiarlos, analizarlos, visualizarlos y concluir.
- Que expliques tu razonamiento, no solo el código: problema → enfoque → resultado.
- Pocos proyectos y bien hechos: de 3 a 5 valen más que 15 a medias.
- Que los puedan ver: código en GitHub, dashboards en Tableau Public, y todo enlazado desde tu página.

## Plan sugerido (cada proyecto cuenta una habilidad distinta)
1. **Análisis exploratorio (EDA)**: empieza con un conjunto de datos y muchas preguntas. Python + pandas + gráficos.
2. **Dashboard**: Power BI o Tableau con datos reales, que cuente una historia con 3 o 4 gráficos.
3. **SQL**: consultas sobre una base de datos con joins y agregaciones; documenta las preguntas que respondes.
4. **Modelo predictivo** (si apuntas a data science): clasificación o regresión con scikit-learn, comparando modelos.
5. **Proyecto con datos de tu entorno**: de tu ciudad, tu pasatiempo o un negocio conocido. Es el más memorable.

## Consejos
- Evita los datasets típicos de tutorial (Titanic, Iris, mtcars): los reclutadores los ven constantemente.
- Prefiere datos desordenados: limpiar es gran parte del trabajo real y demuestra criterio.
- Termina siempre con una **recomendación concreta**, con números ("el 62% de los ingresos viene de clientes recurrentes").
- Cada repositorio en GitHub debe tener un README corto con: problema, datos, herramientas, hallazgos y capturas.
- Nombra los archivos con claridad (`01_limpieza.ipynb`, no `final_v2.ipynb`) y borra lo que sobre.
- Si el proyecto aún no está listo, ponlo como **"En progreso"**: muestra que estás activo.

## Dónde conseguir datos
- Kaggle Datasets: https://www.kaggle.com/datasets
- Google Dataset Search: https://datasetsearch.research.google.com
- World Bank Open Data: https://data.worldbank.org
- OMS / WHO: https://data.who.int
- NASA: https://data.nasa.gov
- Portal de datos abiertos de tu propio país (suele tener datos de salud, economía, transporte, etc.).

## Dónde publicar cada cosa
- Código y notebooks → GitHub
- Dashboards interactivos → Tableau Public (o Power BI publicado en la web)
- Competencias y notebooks → Kaggle
- Tu página (esta) → enlaza a todo lo anterior desde `content.js`
