# Mi portafolio

## Cómo editarlo
1. Abre `content.js` y cambia tus datos (nombre, proyectos, experiencia, contacto).
2. Guarda tus imágenes y tu CV en la carpeta `assets/` (por ejemplo `assets/cv.pdf`, `assets/proyecto1.jpg`).
3. Para ver cambios: haz doble clic en `index.html`.
4. Para el texto que se ve al compartir el link (WhatsApp, LinkedIn), edita las líneas `<meta ...>` y `<title>` al inicio de `index.html`. Pon una imagen de 1200×630 en `assets/preview.png`.
5. Para cambiar el color de acento: `--accent` al inicio de `styles.css`.

## Cómo publicarlo gratis
### Opción A: GitHub Pages
1. Crea una cuenta en github.com y un repositorio nuevo, público, llamado `tu-usuario.github.io`.
2. Sube el contenido de esta carpeta (botón "Add file → Upload files").
3. En Settings → Pages, elige la rama `main` y la carpeta `/ (root)`.
4. Tu link será `https://tu-usuario.github.io`.

### Opción B: Netlify o Cloudflare Pages
Entra a app.netlify.com/drop, arrastra esta carpeta y te da un link al instante.
Puedes cambiar el nombre a algo como `tunombre.netlify.app`.

## Dominio propio (opcional)
Un dominio como `tunombre.com` cuesta unos 10–15 USD al año (Namecheap, Porkbun, Cloudflare).
Se conecta a cualquiera de las opciones anteriores desde su panel.
